# 🎨 Portfólio de Design

Este repositório reúne projetos de **design gráfico e digital**, desenvolvidos com foco em **estratégia, identidade visual e solução de problemas**, não apenas em estética.

Design aqui é tratado como ferramenta de comunicação e posicionamento de marca.

---

## 📌 Sobre o Portfólio

Este portfólio foi criado para mostrar **como penso**, **como decido** e **como executo** projetos de design.

O valor de cada projeto depende de fatores como:
- Complexidade
- Objetivo do cliente
- Tempo de desenvolvimento
- Impacto esperado

Design não é algo genérico. Cada solução é pensada para um contexto específico.

---

## 🧠 O que você vai encontrar aqui

- Identidades visuais  
- Artes para redes sociais  
- Conceitos de branding  
- Projetos experimentais e estudos criativos  

Sempre que possível, os projetos apresentam o **contexto**, o **problema** e a **solução visual** aplicada.

---

## 🎯 Objetivo

Mostrar, na prática, que design vai além de “fazer uma arte bonita”.  
É planejamento, intenção e resultado.
